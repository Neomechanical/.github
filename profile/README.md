# Neomechanical

Neomechanical makes moderation tools for online communities.

- **[Moderator Bot](https://modbot.neomechanical.com)**: a free Discord moderation bot for scams and NSFW.
- **[Neomechanical Moderation API](https://neomechanical.com/platform)**: moderation for your own app or community.
- **[NeoModeration](https://neomechanical.com/neomoderation)**: moderation for Minecraft servers.

More at [neomechanical.com](https://neomechanical.com).
